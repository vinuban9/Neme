How to measure
  • X = full width of the backing plate, end to end, including the ears.
  • Y = height of the backing plate.
  • Z = new pad thickness without the shim. A worn pad will be thinner, so leave Z empty unless the pad is nearly new.
  • Use a vernier if you have one. Width alone usually narrows it down to a few pads, then compare the shapes.
  • The second digit of the number is the maker: D2xxx = Toyota, D1xxx = Nissan.
